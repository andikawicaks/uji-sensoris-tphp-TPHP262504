Uji Perbedaan Atribut: Studi Kasus dengan R

Praktikum Evaluasi Sensori — berdasarkan Meilgaard, Civille & Carr, Sensory Evaluation Techniques, Bab 8

Tentang praktikum ini

Uji perbedaan atribut (attribute difference test) menjawab pertanyaan: “Bagaimana atribut X berbeda di antara sampel-sampel ini?” Berbeda dengan uji perbedaan keseluruhan (misalnya uji segitiga), di sini panelis hanya memperhatikan satu atribut — misalnya kemanisan, kepedasan, atau kerenyahan.

Di praktikum ini kalian akan mengerjakan empat studi kasus. Setiap kasus berisi:

  1. Cerita masalah dari industri pangan.
  2. Data (file CSV) yang bisa diunduh.
  3. Analisis terpandu dengan skrip R yang siap dijalankan.
  4. Tantangan — soal tanpa skrip. Kalian harus menulis skrip sendiri (pendek saja!) dengan memodifikasi skrip yang sudah ada.
Kasus Produk Metode Fungsi R utama
1 Kopi susu gula aren Uji tetrad sensR::discrim()
1b Gula semut di teh, kopi, wedang jahe Uji specified tetrad sensR::findcr(), binom.test()
2 Sambal bawang Uji ranking sederhana (Friedman) friedman.test(), agricolae::friedman()
3 Keripik tempe Uji ranking dengan nilai seri (ties) rank(), agricolae::friedman()

Persiapan

1. Instal paket (cukup sekali)

install.packages(c("sensR", "agricolae", "dplyr", "tidyr", "ggplot2"))
  • sensR — paket khusus uji diskriminasi sensori (tetrad, segitiga, duo-trio, 2-AFC, dll.).
  • agricolae — berisi fungsi friedman() yang langsung memberi uji lanjut dan huruf notasi.
  • dplyr, tidyr, ggplot2 — untuk merapikan data dan membuat grafik.

2. Siapkan folder kerja

  1. Buat RStudio Project baru, misalnya praktikum-uji-atribut.
  2. Di dalam folder project, buat folder bernama data.
  3. Unduh semua file data di bawah ini dan simpan di folder data.
File Dipakai di
kasus1_tetrad_kopi.csv Kasus 1
kasus1b_specified_tetrad_gula_semut.csv Kasus 1b
kasus2_ranking_sambal.csv Kasus 2
kasus3_ranking_seri_keripik.csv Kasus 3
contoh8_6_bir_meilgaard.csv Tantangan Kasus 3

3. Kerjakan di file R Markdown / Quarto

Buat satu file R Markdown (.Rmd) per kasus. Salin skrip dari situs ini ke dalam chunk, jalankan, lalu tulis interpretasi kalian di bawahnya dengan kalimat sendiri.

# baris pertama di setiap file kerja kalian
library(sensR)
library(agricolae)
library(dplyr)
library(tidyr)
library(ggplot2)

Tiga konsep yang harus dipegang

Catatan1. Satu sisi atau dua sisi?

Yang menentukan adalah hipotesis alternatif, bukan jumlah pilihan jawaban di lembar uji. Jika kita hanya ingin membuktikan bahwa sampel B lebih pahit (karena sengaja ditambah hop), itu satu sisi. Jika kita ingin tahu mana yang lebih pahit, itu dua sisi.

Catatan2. Tidak signifikan ≠ sama

Hasil uji perbedaan yang tidak signifikan bukan bukti bahwa sampel sama. Untuk menyatakan “sama” kita butuh uji kemiripan (similarity test) dengan batas perbedaan yang ditetapkan di awal. Ini dibahas di Kasus 1.

Catatan3. Data ranking adalah data ordinal

Ranking hanya memberi urutan, bukan besar perbedaan. Karena itu analisisnya memakai uji Friedman (non-parametrik), bukan ANOVA.
